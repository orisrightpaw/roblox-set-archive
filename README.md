# Roblox Set Archive

Source code for the [Roblox Set Archive](https://sets.pizzaboxer.xyz). Uses ASP.NET Core 6 with Postgres for the API and Vue with Typescript for the frontend.

The Web folder is supposed to contain a frontend Vue project, but I don't have the source files anymore. So, it contains the compiled frontend instead, which can be statically edited, or patched with JS.

If you're setting this up, do not use database migrations. [Download and import the archive database instead](https://mega.nz/file/RLQCwKwY#5mAGC92jyjYCyv_GSTcYMCfDaq9IqKg2EGV81uHjWxs).

This is really old, somewhat broken, and needs to be remade at some point, so don't do anything big with it.
